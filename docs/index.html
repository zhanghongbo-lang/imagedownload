核心功能

从提取到下载，全程只需要点几下。

一键提取

商品详情页右下角悬浮「获取图片」按钮，点击即提取全部商品图片。

懒加载识别

自动读取懒加载图片地址，滚动加载的商品详情图也能完整获取。

图片库预览

新标签页网格展示所有图片，点击缩略图放大预览，Esc 一键关闭。

批量选择

支持全选、取消全选与单选，已选数量实时统计，交互直观方便。

PNG / ZIP 下载

下载单张直接保存为 PNG，下载多张自动打包为一个 ZIP 压缩包。

多平台适配

覆盖淘宝、京东、拼多多三大平台，界面简洁美观、现代清爽。

安装教程

三步完成安装

无需登录、无需付费，本地即可加载使用。

  1. 1

    下载压缩包

    点击右上角「立即下载」，下载扩展压缩包并解压，得到一个包含 manifest.json 的文件夹。

  2. 2

    加载扩展

    打开 chrome://extensions，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择上一步解压出来的文件夹。

  3. 3

    开始使用

    打开淘宝 / 京东 / 拼多多任意商品详情页，点击右下角「获取图片」按钮即可。
